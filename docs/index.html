MMA3001 Smart Infrastructure

Source code documentation for the project structure and core workflow modules.

Project overview

This repository contains a Monash Smart Infrastructure analysis project focused on estimating room occupancy from environmental sensor data. The code is organized around a reusable Python package under src/smart_infrastructure/, with the original notebook-based work retained as historical material.

The project includes configuration handling, data preparation, feature engineering, forecasting models, evaluation metrics, and an end-to-end pipeline runner.

Core workflow summary

Stage Module Purpose
1 config.py Defines project settings, feature groups, dataset paths, and model parameters.
2 data.py Loads the environmental and occupancy data, cleans invalid readings, and builds a modelling table.
3 evaluation.py Evaluates model performance with RMSE, MAE, R², residual diagnostics, and ablation studies.
4 pipeline.py Runs the complete end-to-end workflow and produces the final results and audit files.

Typical usage

from smart_infrastructure import Config, monash_config from smart_infrastructure.data import prepare_env, read_occupancy from smart_infrastructure.pipeline import run_monash cfg = monash_config(env_sensor_id="6012002000869") result = run_monash(cfg, out_dir="results/run1") print(result["selected_model"]) print(result["final_test"])
